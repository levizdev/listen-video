# listen-video — «уши» для ИИ-агента

Превращает звуковую дорожку любого видео в посекундную партитуру: что говорят, какие звуки и мемы стоят, где играет музыка, где удары и паузы. Сделано для разбора чужих Reels/TikTok и проверки своего монтажа, но работает с любым видео или аудио.

**EN:** Turns the soundtrack of any video into a per-second timeline for an AI agent (Claude, etc.): speech with word timestamps, 527 AudioSet sound classes, music segments, zero-shot meme-sound guesses (CLAP), exact matches against your own SFX pack (Shazam-style fingerprints), hits, silences, tempo. CPU only, no API keys.

## Что получаешь

`report.md` — таблица по секундам:

| t, с | Речь | Звуки (AudioSet) | CLAP-догадка | Совпадение с паком | Удар |
|---|---|---|---|---|---|
| 13 | ⏸ | 🎵 | a man saying bruh | Bruh (0.31) | ● |
| 28 | короче смотри | Explosion 🎵 | a loud explosion | | ● |

плюс `report.json` (всё то же машиночитаемо) и `timeline_XX.png` (спектрограмма по 30 с с метками).

| Слой | Модель | Насколько верить |
|---|---|---|
| Речь по словам + уверенность | [faster-whisper](https://github.com/SYSTRAN/faster-whisper) small | хорошо на речи; на песнях галлюцинирует — слова с уверенностью < 0.3 в отчёте в скобках |
| 527 классов звуков (взрыв, сирена, вой, клавиатура, опера, утка…) | [AST AudioSet](https://huggingface.co/MIT/ast-finetuned-audioset-10-10-0.4593) | надёжно при p ≥ 0.4 |
| Где играет музыка | AST «Music» > 0.35 дольше 1.5 с | надёжно |
| Мем-звуки по описанию (vine boom, bruh, скретч, хор, фонк, дубстеп…) | [CLAP](https://huggingface.co/laion/clap-htsat-unfused) zero-shot | **догадка**, подтверждай другими слоями. Поверх речи CLAP часто принимает голос за «bruh» или «glass breaking» — такие догадки помечены `?` и требуют уверенности ≥ 0.6 |
| Точные файлы из твоего пака звуков | `fp.py`, отпечатки как в Shazam | точно, если звук не ускорен и не сдвинут по тону |
| Удары, паузы ≥ 0.35 с, темп | librosa | надёжно |

## Установка

Нужны Python 3.10+, ffmpeg. GPU не нужен.

```bash
git clone https://github.com/levizdev/listen-video && cd listen-video
bash setup.sh            # venv + CPU-версия torch + зависимости
```

Первый запуск скачает модели (~1 ГБ) в `~/hf` (меняется переменной `HF_HOME`).

## Запуск

```bash
.venv/bin/python listen.py reel.mp4 out/ --pack "my sound effects/"
```

| Флаг | Что делает |
|---|---|
| `--pack DIR` | папка с твоими звуками (mp3/wav/m4a…, можно с подпапками) — найдёт, где именно они стоят |
| `--lang ru` | язык речи (по умолчанию `auto`) |
| `--no-asr` | без распознавания речи (быстрее) |
| `--asr-model medium` | точнее речь, медленнее |
| `--vad` | фильтр голоса в Whisper: меньше галлюцинаций на музыке, но может потерять слова |
| `--prompts my.txt` | свои описания звуков для CLAP, по одному в строке (на английском) |
| `--no-png` | без картинок |

Только поиск звуков из пака, без моделей:

```bash
.venv/bin/python fp.py reel.mp4 "my sound effects/"
```

Скорость на 4 CPU: ~1,5–2 минуты на 30 секунд видео (почти всё время — CLAP и AST).

## Как работает поиск по паку

Для каждого звука из пака строятся «созвездия» пиков спектрограммы — пары пиков (частота 1, частота 2, расстояние во времени). Те же пары ищутся в видео. Если звук действительно стоит в ролике, совпадения складываются в один и тот же сдвиг по времени, а случайные совпадения размазаны. Порог — во сколько раз пик выше фонового шума этого звука. Поэтому:

- находит звук под речью и музыкой и после сжатия Instagram/TikTok (AAC 64 кбит/с): 98 % на исходной громкости, 85 % на −6 дБ, 0 ложных срабатываний на 5 реальных роликах;
- находит, даже если в монтаже взяли только первую секунду звука или ускорили его без смены тона;
- **не находит**, если звук сдвинули по тону (pitch), и не индексирует чистые синтетические тоны (бип, «динь» из синусоид). Тихие шумовые звуки («вжух») под другими звуками находит плохо. Для таких случаев смотри слои AudioSet и CLAP.

Результаты стресс-теста (`tests/stress_fp.py`) — в [TESTS.md](TESTS.md).

## Ограничения

- CLAP-метки — догадки, а не доказательство.
- Точное имя мем-звука определяется, только если этот файл есть в твоём паке. Пак = твоя библиотека: чем больше, тем больше узнаёт.
- Название песни не определяет (для этого есть Shazam / [songrec](https://github.com/marin-m/SongRec)).
- Whisper на песнях пишет текст песни — не путай с речью автора.
- Звуковые эффекты, которые намного тише голоса, AudioSet не слышит: модель отвечает «Speech». Если эффекта нет в отчёте, это ещё не значит, что его нет в ролике. Но если его не слышит модель, зритель на телефоне, скорее всего, тоже не услышит.
- Скорость: на 4 CPU примерно 1,5–2 минуты на 30 секунд видео (дольше всего работают CLAP и AST). Первый запуск ещё скачивает модели.
